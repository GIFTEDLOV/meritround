# MeritRound

MeritRound is a GenLayer Project for rubric-based competitions, awards,
accelerators, hackathons, and open calls. The Intelligent Contract owns the
locked evaluation universe, evidence-integrity boundary, validator consensus,
canonical result validation, and terminal round state.

The current baseline includes a functional Vite application shell with real
GenLayerJS reads and writes, wallet/network guards, persistent transaction
recovery, and a deployment record for the development network. Visual polish,
Bradbury proof, and Vercel deployment remain later milestones.

## Current contract

The contract is [contracts/meritround.py](contracts/meritround.py). Its
lifecycle is:

```text
DRAFT -> OPEN -> LOCKED -> EVALUATING -> FINALIZED
                                      \\-> INCONCLUSIVE
```

All submissions registered before locking become finalists in V1. A round
needs two to sixteen finalists. Resolution fetches each HTTPS evidence
document, checks the exact committed SHA-256 digest, validates the bounded
evidence schema, and asks validators to independently produce the same
canonical result:

```json
{"outcome":"WINNER","submission_id":"<canonical-id>"}
```

or:

```json
{"outcome":"INCONCLUSIVE","submission_id":""}
```

No reasoning, scores, rankings, addresses, payouts, or prose are authoritative.

## Local checks

The repository follows the template generated by the installed GenLayer CLI
0.39.1. The installed Python environment currently provides `genlayer-test`
0.29.2 and `genvm-lint` 0.10.0.

```powershell
python -m pip install -r requirements.txt
python -m pytest -q
npm run test:frontend
npm run typecheck:frontend
npm run typecheck:deploy
npm run build
$env:PYTHONUTF8 = '1'
& "$env:LOCALAPPDATA\Python\pythoncore-3.14-64\Scripts\genvm-lint.exe" check contracts/meritround.py --json
```

`check` runs both GenVM linting and semantic contract validation. No private
key is stored in this repository.

## Repository map

- `contracts/` — authoritative Intelligent Contract.
- `tests/direct/` — direct-mode contract tests with mocked web/LLM nondeterminism.
- `tests/frontend/` — lifecycle, wallet guard, persistence, recovery, and readback tests.
- `frontend/` — functional Vite application with dashboard, rounds, creation, submission, detail, and activity routes.
- `deploy/` — deployment helper that waits for finality, checks execution success, and verifies `contract_info()`.
- `deployments/` — public development deployment metadata only.
- `docs/architecture.md` — trust model, evidence boundary, consensus rule, invariants, and frontend lifecycle.
- `docs/development.md` — current SDK compatibility, Studionet deployment, lifecycle, and integration evidence.
- `scripts/` — local verification helpers.

## Scope boundary

MeritRound is the only product in this repository. Tokenomics, governance,
reputation, subscriptions, chat, appeals, admin dashboards, payouts,
Bradbury deployment, Vercel deployment, and visual design are intentionally
outside Hour 2.

## Run the application

Copy `.env.example` to `.env`, confirm the public development contract address
and network, then run:

```powershell
npm install
npm run dev
```

Useful checks are `npm run test:frontend`, `npm run typecheck:frontend`,
`npm run typecheck:deploy`, and `npm run build`.
