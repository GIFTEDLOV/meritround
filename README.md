# MeritRound

MeritRound is a GenLayer Project for rubric-based competitions, awards, accelerators, hackathons, and open calls. The Intelligent Contract owns the locked evaluation universe, evidence-integrity boundary, validator consensus, canonical result validation, and terminal round state.

Hour 1 intentionally focuses on the contract and direct tests. The `frontend/` directory contains only a typed GenLayerJS integration skeleton; there are no visual product surfaces or deployment addresses in this repository yet.

## Current contract

The contract is [contracts/meritround.py](contracts/meritround.py). Its lifecycle is:

```text
DRAFT -> OPEN -> LOCKED -> EVALUATING -> FINALIZED
                                      \-> INCONCLUSIVE
```

All submissions registered before locking become finalists in V1. A round needs two to sixteen finalists. Resolution fetches each HTTPS evidence document, checks the exact committed SHA-256 digest, validates the bounded evidence schema, and asks validators to independently produce the same canonical result:

```json
{"outcome":"WINNER","submission_id":"<canonical-id>"}
```

or:

```json
{"outcome":"INCONCLUSIVE","submission_id":""}
```

No reasoning, scores, rankings, addresses, payouts, or prose are authoritative.

## Local checks

The repository follows the template generated by the installed GenLayer CLI 0.39.1. The installed Python environment currently provides `genlayer-test` 0.29.2 and `genvm-lint` 0.10.0.

```powershell
python -m pip install -r requirements.txt
python -m pytest -q
npm run typecheck:frontend
$env:PYTHONUTF8 = '1'
& "$env:LOCALAPPDATA\Python\pythoncore-3.14-64\Scripts\genvm-lint.exe" check contracts/meritround.py --json
```

`check` runs both GenVM linting and semantic contract validation. The deployment
helper can also be typechecked with the Node.js compiler against the pinned SDK.

The linter path may differ on another machine. No private key, transaction hash, Bradbury proof, or deployment address is committed here.

## Repository map

- `contracts/` — authoritative Intelligent Contract.
- `tests/direct/` — direct-mode contract tests with mocked web/LLM nondeterminism.
- `frontend/` — typed GenLayerJS reads, writes, and transaction reconciliation skeleton.
- `deploy/` — deployment helper that waits for finality and checks execution success.
- `docs/architecture.md` — trust model, evidence boundary, consensus rule, invariants, and frontend lifecycle.
- `scripts/` — local verification helpers.

## Scope boundary

MeritRound is the only product in this repository. Tokenomics, governance, reputation, subscriptions, chat, appeals, admin dashboards, payouts, Bradbury deployment, Vercel deployment, and visual design are intentionally outside Hour 1.
